# Boolean Logic

Booleans have two values: `true` and `false`.

## AND

Both must be true.

```
true  AND true  = true
true  AND false = false
false AND false = false
```

## OR

At least one must be true.

```
true  OR false = true
false OR false = true
true  OR true  = true
```

## NOT

Flips the value.

```
NOT true  = false
NOT false = true
```
