# Binary Numbers

Computers store everything as 0s and 1s.

## Place Values

Each binary digit (bit) represents a power of 2:

```
128  64  32  16  8  4  2  1
```

## Examples

```
0001 = 1
0010 = 2
0100 = 4
1000 = 8
1010 = 12
1111 = 15
```

## Converting to Decimal

Add up the place values where the bit is `1`.

```
1010 = 8 + 2 = 10
```
