# ASCII Table

ASCII (American Standard Code for Information Interchange) is a 7-bit character encoding that maps characters to numeric codes from 0 to 127. This reference separates standard ASCII from the Windows-1252 extension (128–255) shown on the source website. The extended range is not standard ASCII; the same byte values can represent different characters in other encodings.

## Common Character Codes

| Character | Decimal |
| --- | ---: |
| Space | 32 |
| `0` / `9` | 48 / 57 |
| `A` / `Z` | 65 / 90 |
| `a` / `z` | 97 / 122 |

## Complete Table

DEC = decimal, OCT = octal, HEX = hexadecimal, and BIN = binary. Binary values are displayed as eight digits for easy comparison. Control characters are shown using abbreviations. DEL (127) is also a control character.
